MORE ICE, MORE SWEET — ELITE 50K WEBSITE
==========================================

HOW TO RUN IN VISUAL STUDIO CODE
1. Extract More_Ice_More_Sweet_Website.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder...
4. Choose the extracted folder: More_Ice_More_Sweet_Website.
5. Open index.html.
6. Right-click index.html and choose "Open with Live Server" if you have the Live Server extension.
   Or simply double-click index.html to open it in your browser.

FILES
- index.html       Website structure and English text
- style.css        Responsive design, colors, cards, hover effects
- script.js        Mobile menu, flavor filters, flavor detail popups
- assets/          Banner and separate flavor images

NOTES
- Each flavor has a separate image file in assets/.
- The displayed price is ₱270 per flavor.
- The images are cropped from the supplied/generated promotional artwork. Crops are made for the website layout and may not contain every original detail.
- This is a front-end showcase; it does not process orders or payments.
- The site includes a responsible-use notice because the product artwork identifies nicotine.
